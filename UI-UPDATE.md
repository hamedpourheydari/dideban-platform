# Dideban Modern UI — Phase 2

Visual-only redesign. Camera, recording, socket, database, and FFmpeg logic are unchanged.

## Updated
- Product-grade command dashboard
- Live KPI meters for cameras, CPU, RAM, and storage
- Quick operational actions
- Refined sidebar identity and navigation
- Stronger topbar hierarchy
- Improved monitor cards, modals, forms, empty states, and responsive behavior

## Installation
Replace the project files, restart Node.js, then hard-refresh the browser with Ctrl+F5.
