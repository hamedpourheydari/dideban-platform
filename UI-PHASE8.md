# Dideban UI Phase 8

- Desktop sidebar is pinned to the left and forced visible.
- Header and main workspace reserve the sidebar width.
- Camera workspace always exposes four positions.
- Existing live camera nodes are preserved; empty positions are generated as add-camera placeholders.
- Four columns are used on wide screens, 2×2 on normal desktop screens, and one column on mobile.
- Camera, recording, FFmpeg, database and socket logic were not modified.
